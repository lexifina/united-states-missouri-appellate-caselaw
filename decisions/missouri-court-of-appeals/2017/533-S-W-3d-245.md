# Clanton v. State

## Majority (PER CURIAM.)

ORDER
PER CURIAM.
Dwayne Clanton appeals from the judgment denying his Rule 24.035 motion without an evidentiary hearing. There is no clear error here. The “motion in support” filed on appeal, which was taken with the case, is denied. We affirm.
An opinion would have no precedential value nor serve any jurisprudential purpose. The parties have been furnished with a memorandum for their information only, setting forth the reasons for this order pursuant to Rule 84.16(b).
