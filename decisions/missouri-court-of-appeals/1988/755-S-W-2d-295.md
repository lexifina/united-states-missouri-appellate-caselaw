# Vassmer v. Lane

## Majority (PER CURIAM:)

ORDER
PER CURIAM:
Appellant appeals from an order of the trial court dissolving a temporary restraining order which had previously been granted on appellant’s petition to enjoin interference with an easement and for damages.
The order is affirmed. Rule 84.16(b).
