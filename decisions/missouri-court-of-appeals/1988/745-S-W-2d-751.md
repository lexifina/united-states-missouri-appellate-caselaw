# Caffey v. Trice

## Majority (PER CURIAM.)

ORDER
PER CURIAM.
Defendant appeals from trial court’s order sustaining plaintiff’s motion for summary judgment in action for unlawful de-tainer. An extended opinion would serve no jurisprudential purpose. We affirm. Rule 84.16(b).
