# State v. Sanders

## Majority (PER CURIAM:)

ORDER
PER CURIAM:
Charles Sanders appeals his convictions of two counts of selling a controlled substance, a class B felony. The trial court sentenced Sanders to seven-year sentences for each count, to run concurrently. We affirm the judgment of convictions. Because we do not discern any jurisprudential value in publishing an opinion, we issue this summary order. Rule 30.25(b).
