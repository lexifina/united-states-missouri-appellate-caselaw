# Williams v. Goodner

## Majority (PER CURIAM.)

ORDER
PER CURIAM.
Thomas D. Goodner appeals the circuit court’s revival of a 1984 judgment for child support. We affirm. Because we do not discern any jurisprudential value to publishing an opinion, we issue this summary order. Rule 84.16(b).
